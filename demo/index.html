HirePool Website Integration Architecture

The entire HirePool assistant UI, orchestration, dynamic API discovery, and authentication sync are packaged inside the SDK. The HirePool website only requires a single mounting script.

Next.js / React Mount (Zero Assistant Logic on Website)

<!-- Add once to HirePool layout or root page -->
<script
  src="http://localhost:3100/sdk/assistant.js"
  data-assistant-id="hirepool"
  data-auto-mount="true"
  defer
></script>
